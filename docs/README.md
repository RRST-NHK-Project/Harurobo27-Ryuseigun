## 構成

| ディレクトリ | 説明 |
|:---|:---|
| `slides/` | 講習用スライド（pptx）。ROS 2 入門 01〜05 / Ubuntu・ROS 2 基本コマンド / serial_bridge・ros2can 講習 / turtle_teleop / 仮想 PS4 セットアップ |
| `answers/` | 講習課題の解答例（`turtle_teleop` など）。`COLCON_IGNORE` 済みなので colcon はビルドしません |

Markdown の資料はこのディレクトリ直下に置いてください。

## 書くときのめやす

ノードやパッケージを足したら、Markdown を 1 枚足して次のことを書いておくと後で困りません。

- 何をするノードか（1〜2 行）
- 購読 / 配信するトピック名と型
- パラメータと既定値
- 動かし方（`ros2 run` / `ros2 launch` のコマンドをそのまま貼る）
- ハマりどころ、未実装のところ、暫定の値

ファイル名は `<パッケージ名>_<内容>.md` のように中身が分かる名前にしてください。
pptx は diff が見えないので、更新したら何を変えたかをコミットメッセージに残しておきましょう。
